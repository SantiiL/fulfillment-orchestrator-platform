# Definition Of Ready

Readiness preparation must be completed before final Definition of Ready approval. That preparation includes:

* identifying the base branch
* creating or validating the dedicated task branch and worktree
* creating or updating the persisted task ledger with the base branch, task branch, worktree path, current stage, recorded writer events, and the derived writer set

A task is ready for implementation only after that preparation and when it includes:

* a clear goal
* business context
* acceptance criteria
* explicit out-of-scope items
* architectural constraints
* required automated tests
* required manual validation
* documentation impact
* risk classification

Tasks that miss any mandatory item should be clarified before implementation begins.
